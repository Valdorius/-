## 🚀 Как включить игру в GitHub (GitHub Pages)

Чтобы игра открывалась и запускалась прямо из репозитория GitHub по ссылке выше:

1. Перейдите в настройки репозитория:
   **[GitHub -> Valdorius/- -> Settings](https://github.com/Valdorius/-/settings)**
2. В левом меню выберите раздел **Pages** (`Settings` → `Pages`).
3. В блоке **Build and deployment**:
   - **Вариант 1 (автоматически через GitHub Actions, рекомендуется):**
     - В выпадающем списке **Source** выберите **GitHub Actions**.
     - В репозитории уже настроен workflow `.github/workflows/deploy.yml`, который автоматически опубликует сайт при каждом коммите.
   - **Вариант 2 (напрямую из ветки main):**
     - В выпадающем списке **Source** выберите **Deploy from a branch**.
     - В появившемся поле **Branch** выберите ветку `main` и папку `/(root)`, затем нажмите кнопку **Save**.
4. ⚠️ **Важно для приватного репозитория**:
   - Если репозиторий является приватным (Private) и у вас бесплатный аккаунт GitHub, GitHub Pages доступен только для публичных репозиториев.
   - Чтобы игра открывалась у всех в интернете, перейдите в **Settings** → прокрутите вниз до **Danger Zone** → нажмите **Change repository visibility** → **Make public**.
5. Подождите 1–2 минуты, пока завершится публикация, и игра будет доступна по адресу:
   **https://valdorius.github.io/-/**

## 🕹 Управление в игре

- **Клик по экрану** — захват курсора мыши для обзора (Pointer Lock)
- **WASD** — перемещение
- **Shift** — ускорение (бег)
- **Space (Пробел)** — прыжок
- **ЛКМ (Левая кнопка мыши)**:
  - **Меч**: быстрый удар
  - **Лук**: удерживайте для натяжения тетивы → отпустите для выстрела
  - **Посох**: удерживайте для непрерывного потока магических снарядов
- **Esc** — освободить курсор / пауза

## 💻 Локальный запуск

- Дважды кликните по файлу **`START.bat`** — автоматически запустится локальный сервер и игра откроется в браузере по умолчанию.
- Или вручную через терминал:
  ```bash
  python -m http.server 8000
  ```
  и откройте в браузере `http://localhost:8000`.

## 📦 Сборка в автономный EXE (Windows)

1. Установите [Node.js](https://nodejs.org/) (версию LTS).
2. Запустите скрипт **`BUILD_EXE.bat`**.
3. Готовый переносимый исполняемый файл `.exe` будет создан в папке `dist/`.
