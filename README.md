# Voxel Arena

## Как запустить прямо сейчас (без сборки)
Просто запусти **START.bat** — откроется браузер с игрой.
Требуется Python (обычно уже есть на Windows).

## Как собрать EXE
1. Установи **Node.js** с https://nodejs.org (LTS версия)
2. Запусти **BUILD_EXE.bat**
3. Готовый EXE появится в папке `dist/`

Сборка занимает 2-5 минут (скачивает Electron ~80 МБ).

## Управление
- **WASD** — движение
- **Shift** — бег
- **Space** — прыжок
- **ЛКМ** — атака (меч), зарядить и отпустить (лук), держать (посох)
- **F11** — полный экран (в EXE версии)
- **Esc** — выйти из полного экрана
